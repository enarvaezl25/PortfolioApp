# PortfolioApp

Portfolio personal de Enoc Narváez, diseñador visual y UX/UI. Sitio estático generado con Node, sin dependencias.

```bash
node build.js
```

El resultado queda en `dist/`. Más detalles en [LEEME.md](LEEME.md).
